A compact alpha-beta chess engine in 4 KB of Python: 0x88 board, iterative deepening under a fixed 80,000-node budget per move, transposition table, killer moves, MVV-LVA ordering, null-move pruning, LMR, quiescence search with delta pruning, and piece-square evaluation. No clock, no randomness: the same position always gets the same move.

## Run it

```sh
python3 main.py
```
